# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Contact the site owner privately through a verified contact channel and include the affected URL, impact, and reproduction steps. Do not include real customer data.

## Security notes

This project is a static GitHub Pages website. Static hosting does not provide private server-side storage, authenticated administration, or secret protection for browser code. Never commit API secrets, credentials, private keys, or customer records. Public analytics project keys are not secrets, but analytics must not receive names, email addresses, phone numbers, message contents, or other directly identifying information.

Before release, review third-party dependencies and asset licenses, test all forms and links, and check the browser console and network requests. A security policy is not a security audit or guarantee.
